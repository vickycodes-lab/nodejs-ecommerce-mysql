# 🛒 E-Commerce Web Application (Node.js + MySQL)

## 📌 Project Description
This is a full-stack E-commerce web application built using Node.js, Express.js, and MySQL. Users can browse products, add items to cart, and interact with dynamic backend APIs.

## 🚀 Features
- Product listing and dynamic rendering
- Add to Cart functionality
- REST API integration
- MySQL database connectivity
- Responsive UI using HTML, CSS, JavaScript

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL

## 📂 Project Structure
- `public/` → Static files (CSS, JS)
- `views/` → Frontend pages
- `server.js` → Backend server
- `package.json` → Dependencies

## ▶️ How to Run
```bash
npm install
node server.js
